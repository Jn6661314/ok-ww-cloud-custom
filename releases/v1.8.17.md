# v1.8.17 · 修复「开了远控窗口模式，设备下拉还是 PC 客户端」/ Fix stream-window device dropdown

本版改了运行时代码，**必须重跑 `python restore.py` 并重启 ok-ww** 才生效。

## 现象

在「远控串流窗口(试验性)」里把 `Enable` 打开后，设备下拉列表里**还是只有鸣潮 PC 客户端**，
看不到 UU远程 / ToDesk / Moonlight 等远控窗口，选不到远控设备。

## 根因

配置里 `Enable=true`，但 `Preset=Manual` 且 `Window Title=""`（窗口标题为空）。
旧逻辑 `apply_stream_window()` 一旦发现标题为空就打一句「没填窗口标题，继续使用默认 PC 设备」
然后直接返回，`set_stream_window()` 从未执行 —— 于是远控模式等于没开，下拉自然还是 PC 客户端。

也就是说：**开关打开了却被静默忽略，而且 GUI 里没有任何提示**。这是产品逻辑缺陷，不只是配置问题。

## 修复

1. **未填标题也启用远控模式**：`apply_stream_window()` 不再因标题空而返回 False，
   改为调用 `set_stream_window(None)` 进入「列出所有窗口」模式。
2. **列出所有可见窗口**：`set_stream_window(None)` 把 `exe` / `title` / `hwnd_class` /
   `top_hwnd_class` 四个过滤全部清空，`update_pc_device()` 会枚举本机所有可见窗口，
   设备下拉里就能看到远控窗口，手动选中即可（选中后仍强制 Pynput 真实键鼠）。
3. **填了标题仍是精确匹配**：Preset 或手填 Window Title 时行为不变，只匹配标题命中的远控窗口。
4. **日志明确提示**：未填标题时会打印「设备下拉会列出所有可见窗口，请从中选远控/串流窗口」
   并建议填 Preset 或 Window Title 以便自动匹配，不再静默退回。

## 你需要做的

1. 重跑 `python restore.py`，重启 ok-ww。
2. 打开「远控串流窗口(试验性)」配置页确认 `Enable=true`（本版起，标题留空也能用）。
3. 到设备下拉列表刷新，应该能看到所有可见窗口；从中选中远控/串流窗口即可。
4. 若能确定远控软件，建议把 `Preset` 选成对应软件（UU远程/ToDesk/向日葵/Parsec/Moonlight），
   或手填 `Window Title`，这样下拉只列匹配的窗口，更省事。
5. 仍要求：被控电脑上游戏全屏 16:9、远控窗口客户区 16:9 无黑边，否则比例告警会提示。
