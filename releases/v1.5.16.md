# v1.5.16 · 拉海洛方块支持关卡详情页直接开始 / Rahai Blocks: start directly from stage details page

## 中文

### 背景
此前「3.8 拉海洛方块·逆转」任务启动时**必须停在活动关卡列表页**，否则直接报错：
`请先打开简体中文的「拉海洛方块·逆转」活动关卡列表。`
玩家如果已经手动点进了某个关卡（详情页，含"关卡目标/开始挑战"），任务无法启动。

### 新增
- 任务启动时先找关卡列表页；找不到则探测**关卡详情页**（OCR "关卡目标"）：
  - 命中 → **直接开始当前选中的难度**（OCR 识别"困难/简单"，不会误切难度）；
  - 打完这一关后照常返回列表页，继续扫描挑战其余已解锁未通关关卡；
  - 直启失败（识别不到难度/开始按钮等）只记一条告警，**不中断**后续列表扫描。
- 列表页入口行为完全不变；两个页面都不在时保持 FatalTaskError，
  提示信息更新为"活动关卡列表**或任一关卡详情页**"。

### 实现
- `_challenge` 尾部公共流程（识别关卡目标 → 点开始挑战 → 下棋 → 领奖励）
  提取为 `_start_and_play(interaction, difficulty, label)`；
- 新增 `_challenge_current_details(interaction)`：详情页直启入口；
- `_run_task` 入口路由：列表页 → 原流程；详情页 → 直启后回列表；都不在 → 报错。

### 验证
- 新增 `tests/TestRahaiBlocksEntry.py`（9 项：入口路由 ×3、详情页直启 ×3、
  公共开始流程 ×3）全部通过；
- 既有 `TestRahaiFaults.py` 回归通过；
- `restore.py` 部署 working + repo，`RahaiBlocksTask.py` 三处哈希一致。

## English

### Background
The "3.8 Rahai Blocks" task previously **required the stage list page** to be open
before starting, otherwise it raised:
`Please open the zh-CN "Rahai Blocks" event stage list first.`
If the player had already opened a stage details page (with stage goal / start
button), the task could not start.

### Changes
- On startup the task looks for the stage list first; if absent it probes the
  **stage details page** (OCR "stage goal"):
  - Found → **starts the currently selected difficulty immediately** (OCR detects
    困难/简单; never switches difficulty by accident);
  - After clearing that stage it returns to the list as usual and keeps scanning
    the remaining unlocked/incomplete stages;
  - Direct-start failures only log a warning and never abort the later scan.
- List-page entry behavior is unchanged; when neither page is open the
  FatalTaskError remains, now mentioning "stage list **or any stage details page**".

### Implementation
- Extracted the shared tail of `_challenge` (goal check → start → play → claim)
  into `_start_and_play(interaction, difficulty, label)`;
- Added `_challenge_current_details(interaction)` for the details-page entry;
- `_run_task` routing: list page → original flow; details page → direct start
  then back to list; neither → error.

### Verification
- New `tests/TestRahaiBlocksEntry.py` (9 tests: routing ×3, direct start ×3,
  shared flow ×3) all green;
- Existing `TestRahaiFaults.py` regression passed;
- Deployed via `restore.py`; hashes identical across custom/working/repo.
