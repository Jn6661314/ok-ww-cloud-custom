# v1.5.18 · 拉海洛方块直接支持无尽模式 / v1.5.18 Rahai Blocks: full Endless Mode support

## 中文

### 背景（2026-11-25 实测）
v1.5.17 对无尽模式采取"明确拒绝"策略（报"暂不支持自动挑战"）。用户要求直接兼容：
无尽模式没有简单/困难难度选项，但完全可以自动游玩。实测截图确认：
1. 无尽模式详情页与普通关卡一致（有"关卡目标"、开始按钮），仅无难度页签；
2. 开始后先弹"无尽模式"玩法说明弹窗（v1.5.17 已能自动点确认）；
3. 局内左上有"历史最高"与"达到9999分结算可得首通奖励"——既是局内特征，
   也给出了目标分数；达到要求后需**退出并结算**才能领取关卡奖励。

### 改动
- **三种入口全部支持**：
  1. 无尽模式详情页 → `_challenge_current_details` 识别无难度 + 无尽特征后
     直接转 `_challenge_endless` 开始；
  2. 已在对局内（玩法弹窗/局内 UI/棋盘可见任一）→ `_run_task` 新增
     `_endless_ingame` 分支直接加入继续游玩；
  3. 关卡列表扫描流程不变，普通简单/困难关卡照常挑战。
- **`_challenge_endless` 主流程**：点掉玩法弹窗 → 点开始（首局）→ 一直落块消行。
- **目标分退出结算（`_endless_exit_and_settle`）**：OCR 解析"达到N分结算"得到目标分，
  每 10 步核对左上计分条当前分数，达到后点 X → 退出确认（离开/确认/确定变体）→
  结算奖励；OCR 读不到分数/目标时退化为一直游玩直到无合法落点，由游戏自动结算。
- **`_play_board` 无尽模式适配**：新增 `endless/max_moves` 参数（无尽上限 600 步）；
  无合法落点视为本局结束（返回 'dead'）而不是报错；棋盘消失视为进入结算界面；
  结束原因（reward/dead/goal/cap/ended）记入日志。
- **开始按钮宽域兜底**：`_challenge_button(wide=True)` 在窄域"开始挑战"识别失败时，
  宽域匹配"^开始(挑战)?$"，兼容手游端按钮位置偏移。
- 局内特征正则：`历史最高`、`达到N分结算`（繁体兼容）；弹窗特征
  `玩家可以一直游玩|直到失败`。

### 使用说明
- MuMu/安卓端游玩仍需**保持 MuMu 窗口在前台**（真实鼠标拖拽 + R 旋转）。
- 无尽单局可能持续较长（最多 600 步），期间请勿操作鼠标键盘。

### 测试
- `TestAndroidMuMuFixes.py` 扩充至 38 项：无尽详情页直启 / 加入局内 /
  目标分解析与退出结算 / 宽域开始按钮 / `_play_board` 无尽与普通模式行为差异 /
  局内特征识别。
- 全部 15 个测试套件通过（3 个套件因既有模块布局问题需 PYTHONPATH，与本次无关）。

## English

### Background (verified 2026-11-25)
v1.5.17 deliberately rejected Endless Mode ("not supported"). This release adds full
support: Endless has no Easy/Hard difficulty tabs but is fully playable. Screenshots
confirm the endless detail page matches normal stages (objective + start button),
the tutorial popup is already handled, and the in-game HUD shows "历史最高" plus
"达到9999分结算可得首通奖励" (reach 9999 points then exit & settle for first-clear
reward).

### Changes
- Three entry paths all supported: endless detail page direct start; joining a
  running endless game (via popup text / in-game HUD regex / visible board);
  normal stage-list scanning unchanged.
- `_challenge_endless`: dismiss tutorial popup → click start → keep placing blocks.
- `_endless_exit_and_settle`: parse goal from "达到N分结算" OCR, check the top-left
  score bar every 10 moves, then X → leave/confirm → settlement reward. Falls back
  to playing until no legal move (auto-settle) if OCR unavailable.
- `_play_board` endless params: move cap 600, dead-end returns instead of raising,
  board disappearance treated as settlement entry, end reason logged.
- Wide-area start-button fallback matches "^开始(挑战)?$".
- Tests extended to 38 cases; 15 suites green.
