# v1.8.29 · 关掉 ok-ww 后投屏内核不再残留，配置里可手动关闭投屏 / Mirroring engine no longer lingers after ok-ww exits

这版只修一件事：**关掉 ok-ww 后投屏内核还在后台跑**。内核残留会占着端口、导致下次配对
误复用旧内核（二维码出不来），手机端也会因为两个内核抢同一个设备身份而显示「电脑离线」。

## 一、根因

`stop_engine()` 早就写好了，但**没有任何地方调用它**：

- 内核是用 `subprocess.Popen` 起的独立进程，ok-ww 退出时 Windows 不会自动结束它；
- 配置菜单里只有「启动投屏内核」，没有关闭入口；
- 上一版把内核设计成跨 ok-ww 重启常驻（省得每次在手机上点「允许」），代价就是残留进程
  会一直占端口、干扰下一次配对。

## 二、修法：三道保险

1. **正常退出**：模块加载时注册 `atexit.register(stop_engine)`。关窗口、Ctrl+C、
   `sys.exit()` 都会干净地停掉内核。
2. **强杀 / 崩溃**：把内核进程放进一个带 `KILL_ON_JOB_CLOSE` 标志的 Windows Job Object，
   job 句柄由 ok-ww 持有。ok-ww 无论怎么消失（任务管理器结束、崩溃），系统都会在最后一个
   句柄关闭时把内核一起结束。已在真实 Windows 上验证：绑定后关闭句柄，子进程立刻退出。
   绑定失败（老系统/权限受限）不影响内核启动，还有 atexit 兜底。
3. **手动关闭**：配置 → 手机投屏 新增「**停止投屏内核（关闭投屏）**」按钮，
   不用退出 ok-ww 就能彻底关掉投屏；再投屏点「启动投屏内核」或重启 ok-ww。

行为变化：投屏**不再跨 ok-ww 重启常驻**。下次开 ok-ww 要重新投屏时，
按 Android MediaProjection 的规定需要在手机上再点一次「允许」。

## 三、测试口径纠正

之前说的「全量 236 项」其实只是 `working/tests` 下框架自带的 10 个文件，**漏掉了定制仓库
`tests/` 里的 29 个文件**。这次用正确路径跑：**486 项测试全绿**，其中新增 5 项专测退出清理

按之前的约定没有做实机游戏验证；投屏退出是否干净由你在实机上确认。

## English summary

**The mirroring engine kept running after ok-ww was closed.** `stop_engine()` existed but was never
called: the sidecar is a separate `Popen` process, so Windows did not terminate it with ok-ww. The
leftover process held the port, caused pairing to reuse a stale engine (no QR code), and made the
phone show the PC as offline.

Three layers of cleanup:

1. `atexit.register(stop_engine)` for normal shutdown (window close, Ctrl+C, `sys.exit()`).
2. A Windows Job Object with `KILL_ON_JOB_CLOSE` for task-manager kills and crashes — verified on
   Windows: closing the job handle terminated the child immediately.
3. A new **"Stop mirroring engine"** button in the phone-mirroring config menu, so mirroring can be
   turned off without quitting ok-ww.

Mirroring no longer survives an ok-ww restart; Android will ask for permission again next time.

**Test-count correction:** the previously reported "236 tests" only covered the framework's own
tests in `working/tests` (10 files). The custom repository has 29 more test files; with the correct
path the full suite is **486 tests, all passing**, including 5 new tests for exit cleanup.

No in-game verification was done for this release, by prior agreement.
