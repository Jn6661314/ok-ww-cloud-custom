# v1.0.1 · Agent 一键安装提示词 / Agent-Assisted Install Prompt

## 中文

新增 [`AGENT_INSTALL_PROMPT.md`](https://github.com/Jn6661314/ok-ww-cloud-custom/blob/main/AGENT_INSTALL_PROMPT.md)：把下面整段复制给你使用的 Agent（WorkBuddy / Claude / Cursor 等），它就能自动在本机完成安装与验证。

```text
请帮我在本机安装 ok-wuthering-waves 的「云鸣潮定制补丁」，仓库地址：
https://github.com/Jn6661314/ok-ww-cloud-custom

这是一个非官方第三方补丁，依赖官方原版 ok-wuthering-waves（上游：
https://github.com/ok-oldking/ok-wuthering-waves）。请尽量自动完成，不要让我手动操作。

执行要求：
1. 先检查是否已安装官方原版 ok-ww（pyappify 安装版，运行目录通常是
   %LOCALAPPDATA%/ok-ww/data/apps/ok-ww/working），并确认 Python 可用。
   如果没装官方原版，请告诉我并给出上游安装方式，不要自行替我安装。
2. 关闭正在运行的 ok-ww 进程，避免文件被占用。
3. 克隆或下载本仓库到本地临时目录，进入仓库目录。
4. 运行安装脚本：
   python tools/install_to_local_app.py
   如果提示找不到 working 目录，请让我提供实际路径，然后带参数重跑：
   python tools/install_to_local_app.py "你的working目录路径"
5. 脚本自动完成：复制新增/修改的源码、给 config.py 注册云任务与「角色代码」页、
   打浏览器后台运行与云游戏进入检测补丁、放入工坊离线缓存，并把被改文件备份为
   .pre-cloud 后缀。请勿手动改动 Cookie、MultiAccountConfig.json、自定义队伍文件。
6. 启动 ok-ww，选择设备「云游戏」，确认能看到「云每日」「云多账号」「保存 Cookie」
   「切换账号」任务，以及「角色代码」页（含工坊）。
7. 如果之后官方更新把补丁覆盖了：关闭 ok-ww 后运行 python restore.py 或双击
   一键恢复.bat；大版本结构变化则重跑第 4 步的安装脚本。详见 docs/backup-and-restore.md。

请逐步执行并汇报结果。遇到报错先自行排查修复（比如路径、Python 版本、文件占用），
不要停下来问我，除非确实需要我提供安装路径或登录凭据。完成后告诉我可以开始使用。
```

安装脚本会先备份被修改的文件，且**不会**覆盖你的 Cookie、多账号配置和自定义队伍。

## English

Added [`AGENT_INSTALL_PROMPT.md`](https://github.com/Jn6661314/ok-ww-cloud-custom/blob/main/AGENT_INSTALL_PROMPT.md): copy the block below into the Agent you use (WorkBuddy / Claude / Cursor, ...) and it can complete the installation and verification on your machine automatically.

```text
Please install the "Wuthering Waves cloud custom patch" of ok-wuthering-waves on this
machine. Repository:
https://github.com/Jn6661314/ok-ww-cloud-custom

This is an unofficial third-party patch and depends on the official ok-wuthering-waves
(upstream: https://github.com/ok-oldking/ok-wuthering-waves). Please do as much as
possible automatically and do not make me operate manually.

Requirements:
1. First check whether the official ok-ww is installed (the pyappify build; its run
   directory is usually %LOCALAPPDATA%/ok-ww/data/apps/ok-ww/working) and confirm
   Python is available. If the official build is missing, tell me and give me the
   upstream installation instructions — do not install it on my behalf.
2. Close any running ok-ww process so files are not locked.
3. Clone or download this repository into a local temporary directory and enter it.
4. Run the install script:
   python tools/install_to_local_app.py
   If it reports that the working directory was not found, ask me for the real path
   and re-run with an argument:
   python tools/install_to_local_app.py "path/to/your/working/directory"
5. The script then: copies the new/modified sources, registers the cloud tasks and the
   "Character Code" tab in config.py, applies the browser background-run and
   cloud-game entry-detection patches, drops in the offline workshop cache, and backs
   up every modified file with a .pre-cloud suffix. Do not manually modify Cookies,
   MultiAccountConfig.json, or custom team files.
6. Start ok-ww, select the "Cloud" device, and confirm you can see the "Cloud Daily",
   "Cloud Multi-Account", "Save Cookie" and "Switch Account" tasks, plus the
   "Character Code" tab (which contains the workshop).
7. If a later official update overwrites the patch: close ok-ww and run
   python restore.py or double-click 一键恢复.bat; if the structure changes in a major
   version, re-run step 4. See docs/backup-and-restore.md.

Please execute step by step and report the results. If something fails, troubleshoot
and fix it yourself (paths, Python version, file locks, ...) instead of stopping to
ask me, unless you really need an installation path or login credentials from me.
Tell me when I can start using it.
```

The install script backs up every file it modifies and **never** overwrites your Cookies, multi-account configuration, or custom teams.
