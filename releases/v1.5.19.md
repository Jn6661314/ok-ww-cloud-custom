# v1.5.19 · 无尽模式直启兜底 + 云游戏卡死修复 / v1.5.19 Endless direct-start fallback + cloud game hang fix

## 中文

### 背景（2026-11-25 18:28~18:33 实测日志）
1. **无尽详情页直接退出**：18:28:35 任务在无尽详情页识别到"关卡目标"，但
   `_endless_page()` 的三个 OCR 区域全部落空（无尽详情页没有可见的"无尽模式"
   标题文字），报"无法识别关卡页面当前选中的难度"后 `_return_to_list()` 点 X
   直接退出了页面——用户看到的就是"在关卡页面直接退出而不是进入挑战"。
2. **任务卡死**：18:29:28 后任务日志静默 71 秒，直到用户手动停止。该会话运行在
   **云游戏(browser)** 设备上；`BrowserCaptureMethod.run_in_loop` 用
   `future.result()` 等待 CDP 调用完成且**无超时**——浏览器卡顿/假死时，
   `_place` 拖拽的鼠标事件调用永久阻塞，任务静默卡死。

### 改动
- **直启兜底（`_challenge_current_details`）**：难度识别（窄域+宽域）与无尽特征
  全部失败时，只要页面上有"开始挑战/开始"按钮就直接开始（跳过积分/奖章目标
  检查），不再报错退页。
- **无尽自动分流（`_start_and_play`）**：点开始后若实际进入无尽模式（玩法弹窗或
  局内"历史最高/达到N分结算"特征），自动转 `_play_endless_round` 无尽流程
  （含目标分退出结算/无落点自动结算）；普通关卡照常走棋盘流程。
- **结构复用**：新增 `_click_start()`（点开始直到按钮消失）与 `_play_endless_round()`
  （无尽对局公共流程），`_challenge_endless` 与兜底直启共用。
- **卡死修复（`run_in_loop`）**：CDP 调用等待加 15 秒超时，超时后取消调用、
  告警放行，任务自动继续；被卡协程在下一个 await 点被取消。云游戏浏览器频繁
  卡顿时日志会给出提示。

### 测试
- `TestAndroidMuMuFixes.py` 扩充至 45 项：兜底直启（有按钮必须开始、无按钮仍报错）、
  直启后无尽/普通分流、`run_in_loop` 正常返回/卡死超时/异常吞掉三个场景。
- `TestRahaiBlocksEntry.py` 桩适配 `wide` 参数，9 项全绿；全部 15 个套件通过。

## English

### Background (verified 18:28~18:33 logs)
1. **Endless detail page exited instead of starting**: `_endless_page()` OCR found
   no endless markers on the detail page, so the task raised "cannot identify
   difficulty" and `_return_to_list()` clicked X, leaving the page.
2. **Task hang**: 71 silent seconds then manual stop. The session ran on the
   cloud (browser) device; `run_in_loop` waited on CDP calls with **no timeout**,
   so a stalled browser blocked drag mouse events forever.

### Changes
- Fallback in `_challenge_current_details`: when difficulty and endless markers
  are all unreadable but a start button exists, start directly (skip the
  score/medal objective check) instead of erroring out.
- `_start_and_play` auto-detects entering endless mode after clicking start and
  redirects to the endless round flow; normal stages unchanged.
- New shared helpers `_click_start()` / `_play_endless_round()`.
- `run_in_loop` now times CDP calls out at 15s, cancels the stuck coroutine and
  continues with a warning instead of hanging forever.
- Tests extended to 45 cases; 15 suites green.
