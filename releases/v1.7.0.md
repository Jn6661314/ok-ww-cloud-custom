# v1.7.0 · 把 MuMu / 安卓模拟器支持合并回官方 v3.8.15 基线

## 背景

v1.6.0 为了能干净地向上游提 PR，整份代码换成了官方 v3.8.15，并且把 MuMu / 安卓定制
留在了 `legacy-mumu-v1.5.21` 分支。本版把这些定制**重新合并回主线**（基线仍是官方
v3.8.15 / ok-script 3.0.14），于是同一支 main 同时支持：PC 客户端、云鸣潮、MuMu/安卓模拟器。

合并方式不是整文件覆盖：以官方 v3.8.14 为共同祖先做三方合并，
**官方 v3.8.15 的所有新特性（云战斗宽限、协奏环新算法、Cultivation 刷取、切换链限制等）
全部保留**，只把 MuMu 相关的增量叠上去。

## 一、设备与框架层

| 改动 | 文件 | 说明 |
| --- | --- | --- |
| 模拟器重新出现在设备下拉 | `config.py` | 恢复 `'adb': {packages, capture_method: 'ipc'}`；非 MuMu 模拟器没有 ipc 通道时由 `get_preferred_capture()` 自动回退到 adb 抓屏 |
| 开机自动拉起游戏 | `ok/device/DeviceManager.py` | 设备就绪后发 LAUNCHER intent 拉起鸣潮，20 秒冷却避免反复拉；与抓屏方式无关（原来只在 adb/ipc 分支里执行） |
| MuMu 网桥回退 | `ok/device/DeviceManager.py` | `127.0.0.1:port` 无人监听时从 ARP 表找虚拟机 IP，试 5555 / 16384 |
| 模拟器窗口抓屏 + 交互 | `ok/device/DeviceManager.py` | 选「窗口抓屏」时补建 `win_interaction_class`（原来 interaction 会是 None，点击/按键全部失效） |
| IPC 全黑帧自恢复 | `ok/device/capture_methods/nemu_ipc.py` | 返回全黑帧时重建 IPC 连接并重试；登录/加载期 30 秒冗余窗口内继续等，超时才报可读错误 |
| ADB 键位表 | `ok/device/interaction_methods/keys.py` | `esc → KEYCODE_BACK`；补 F1-F12、A-Z、0-9、反引号，避免非法的 `input keyevent f` |
| Win10 WGC | `ok/util/window.py`、`windows_graphics.py` | WGC 可用性不再被 Win11 门禁（20348）误杀；`IsBorderRequired` 失败降级，Win10 云抓屏/窗口抓屏不再有黄框 |

## 二、业务层（ok-ww）

### 触屏语义层

新增 `src/task/touch_mode.py`，把"返回 / 打开菜单 / 指南书 / 活动面板"收敛到一处：

- 触屏端返回与打开菜单是**同一个按钮**，就是键位表的 ` 键；`BaseWWTask.back()` 与
  `send_key('esc')` 在触屏下统一改写为 `，不再弹"是否退出游戏"。
- 指南书（PC 的 F2）与活动面板（PC 的 F1）改为**点右上角对应图标**（触屏没有 F 键）。
- `BaseWWTask` 新增 `_adb_keymap_available / _adb_focus_window / _adb_real_key`：
  在 ADB 输入之上**叠加一次真实键盘事件**，由模拟器键位映射转成触屏操作——
  手游不认 `input keyevent`，这是"手动按 Y 能锁敌、脚本按键毫无反应"的根因。

### 大世界与战斗判定

- 新增 `src/task/android_world.py`：手游队伍栏没有 1/2/3 数字徽章，PC 模板永远匹配不上，
  改用雷达黄色玩家箭头 / 协奏金球 / 血条组合判定，并单独识别"贯穿全屏的加载进度条"
  和"全黑帧"（否则表现为 `ensure_main` 卡 600 秒无日志）。
- 新增 `src/task/android_book.py`：索拉指南是移动端布局，PC 类别图标 NCC 会命中背景空白；
  改用白色笔画掩码 + 多尺度 IoU 配对定位左列图标，并据此判断"书是否已打开"（不再来回点开关）。
- `CombatCheck`：锁敌改 Y 键（`tap_target`）、谐振破坏改为模板 + OCR（不再按 F）、
  无血条时重锁定耐心 8 秒并先重试一轮、连续无敌人退出窗口 4 秒、整帧黑保护。
- `BaseCombatTask`：编队锁定（见下）、切人键只在 1/2 两颗里推导（绝不发 3）、
  安卓协奏环专用检测框（PC 框在手游上够不到弧，导致 current_con 恒 0、永不放延奏）、
  切人期间用脚本维护的逻辑下标（HUD 头像消失时 `in_team()` 会返回 -1）。
- `AutoCombatTask` / `BaseCombatTask` / `MouseResetTask`：角色对象为空、抓屏没有
  `get_abs_cords` 等情况下不再抛异常把触发任务关掉。

### 掉线与健壮性

- `BaseWWTask.handle_android_disconnect()`：亮度预筛 + OCR 确认「连接已断开」弹窗，
  点「确认」后复位登录态交给自动登录；15 秒节流避免重复点击。
- 10 分钟内掉线 ≥3 次时提示一次排查建议（关闭后台省电/限帧、别最小化、`networkReset.bat`、换 DNS）。
- `handle_monthly_card()` 误报防护：任务中途不再把邮箱奖励当成年卡，连续 3 次"检测到但领不到"
  就本次运行跳过，避免 `ensure_main` 超时 → 错误恢复反复重启的死循环。
- `walk_to_treasure()` 在安卓上找不到宝箱时先回去清残象再重走，仍找不到交回上层 rechallenge 循环。

### 编队（重点）

手游队伍栏是圆形头像（约 1.7 倍大），PC 头像模板固定尺度匹配会抖动，导致"该切奶妈却切主C"。

1. 全局配置新增「MuMu/安卓 Config → MuMu 编队」：手填角色名（中文/英文），**编队为准，零画面识别**；
2. 不填则把队伍栏缩放 0.58 倍到 PC 尺度识别，连续 3 次一致才锁定；
3. 锁定后战斗期间完全不复检，非战斗每 15 秒复检一次，换队自动重锁；
4. 识别环节任何异常只记一条日志并回退上游 PC 框路径（保证战斗不中断）。

### 每日任务

`DailyTask.open_daily()` / `get_total_daily_points()` 增加安卓分支：先 OCR 定位「活跃行迹」
子页签，再宽域识别 `x/180` 与 `x/100`（分母限定过滤任务进度，优先取"活跃度"附近读数）。
**日常任务仍然只注册一次**，按所选设备自动切换；`src/task/AndroidDailyTask.py` 保留为
可选的显式入口，默认不注册，避免任务列表里出现两个每日任务。

## 三、拉海洛方块（MuMu + 无尽模式 + 关卡页直启）

`src/task/RahaiBlocksTask.py` 现在同时支持三种设备：

| 设备 | 输入通道 | 说明 |
| --- | --- | --- |
| 云鸣潮 | `BrowserInteraction`（CDP 虚拟输入） | 不需要窗口在前台 |
| **MuMu/安卓** | `PynputInteraction`（模拟器窗口键鼠） | 跳过"必须有 PC 游戏窗口"的检查；返回列表失败时用安卓返回键兜底 |
| PC 客户端 | `PynputInteraction` | 与原版一致 |

无尽模式与关卡页直接启动（v1.6.0 已实现，本版在三种设备上都可用）：

- 无尽详情页（没有简单/困难页签）直接开始，不会走"无法选择难度"退页；
- 可加入已在进行中的无尽对局；
- 局内解析「达到 N 分结算」，每 10 步读一次分数，达标后点 X → 离开 → 领奖；
- 无合法落点 / 棋盘消失返回 `dead` / `ended` 交给游戏自己结算，不再当失败抛异常；
- 玩法说明弹窗自动确认，「立即前往」自动返回关卡列表。

## 四、测试

- 新增 `tests/TestMumuSupport.py`（24 项）：adb 设备声明、键位表、全黑帧、adb 拉起节流、
  安卓大世界判定（雷达/加载条/断线弹窗）、触屏返回语义、`esc → ` 改写、真实键叠加。
- `tests/TestRahaiEndless.py` 增加 4 项 MuMu 用例：Pynput 输入、前台判定、返回键兜底、
  PC 下不发返回键。
- 全量回归 **193 项通过**；config 里注册的 21 个任务全部可导入；全部源码 `compileall` 通过。

## 五、升级提示

1. 关闭 ok-ww，执行 `python restore.py`（或双击 `一键恢复.bat`）；
2. 设备下拉里选 MuMu 模拟器 → 照常跑同一个「每日任务」/「拉海洛方块」；
3. 首次建议在「设置 → MuMu/安卓 Config」里**手填编队**，战斗识别最稳；
4. 账号 Cookie、多账号配置、自定义队伍都不会被覆盖。

## English summary

v1.7.0 merges the MuMu/Android emulator support back onto the official ok-ww v3.8.15 baseline
(three-way merge with v3.8.14 as the common ancestor, so every upstream 3.8.15 improvement is kept).

- Device layer: emulator shows up again in the device list, MuMu IPC capture with black-frame
  recovery, boot-time game launch with cooldown, MuMu bridge (ARP) fallback, complete ADB key map,
  WGC usable on Windows 10.
- Game layer: touch-semantics layer (back/menu = the `` ` `` key), HUD-based world detection,
  guild-book icon location by stroke IoU, team lock (manual team first, then scaled detection with
  voting), combat fixes (Y to target, break by OCR, patient re-target), disconnect dialog handling.
- Rahai Blocks now runs on MuMu as well, with Endless Mode and direct start from a stage page.
- 193 unit tests pass. `DailyTask` is still registered only once and adapts to the selected device.
