# v1.8.19 · 手机投屏(NectarLink)驱动真机玩鸣潮，取代 MuMu 模拟器 / Drive a real phone via NectarLink screen mirroring

本版改了运行时代码，**必须重跑 `python restore.py` 并重启 ok-ww** 才生效。

## 背景

MuMu 模拟器上跑鸣潮有一堆绕不开的问题：拖方块落点偏移、切人永远停在 1 号位、必须前台、
键位映射要靠模拟器功能。根本原因是模拟器的**触控坐标与截图坐标是两套坐标系**，
横竖屏/缩放/黑边任一不一致就会整体偏移（v1.8.12~v1.8.16 连续五版都在修这个）。

NectarLink（开源，github.com/thtbee/nectarlink）把手机画面投到 PC 的一个独立窗口里，
并把鼠标点击按**屏幕比例**转发回手机。它的协议文档（`docs/protocol/mirror.md` §4）写得很清楚：

> Positions are fractions of the screen as the phone shows it now (0 at the left or top,
> 1 at the right or bottom), so they hold at any size and rotation.

桌面端也确实是这么做的（`desktop/app/qml/MirrorWindow.qml`）：
`video.at(x, y)` 用 `pictureRect()` 把窗口内位置换算成视频帧内的 0~1 比例，再 `Mirror.touch()` 发给手机。

**这意味着坐标换算由投屏软件全权负责** —— 缩放、黑边、横竖屏、窗口大小变化全都不影响落点。
之前在 MuMu 上折腾不出来的稳定性，这里直接绕开了。

## 本版做了什么

把 NectarLink 的**手机投屏窗口**接进 ok-ww 当成一种设备：

### 1. 新增「NectarLink 手机投屏」预设

「远控串流窗口(试验性)」的 Preset 下拉新增该选项，自动匹配窗口标题 `<设备名> · NectarLink`
（对应 NectarLink 桌面端的投屏窗口标题，见 `MirrorWindow.qml` 的 `title` 属性）。

抓屏与输入复用已有的 windows 链路（抓窗口 + Pynput 真实键鼠），
**不需要改动 nectarlink 任何代码，也不需要自己实现 QUIC/CBOR 协议**。

### 2. 手机投屏设备按「安卓端」处理

投屏窗口里是手游画面，所以编队识别、切人键位、大世界判定都应该走安卓分支。
实现上给设备条目打 `phone_mirror` 标记，并在 `BaseWWTask.is_adb()` 里认它：

```python
if device.get('phone_mirror'):
    return True
```

这样 v1.8.18 刚修好的**编队识别首次即锁定**、**编队角色下拉点选**、**切人键 1/2 映射**
全部直接生效，不用再改一行战斗逻辑。

### 3. 手机投屏不做 16:9 裁剪、不弹 16:9 告警

远控窗口模式原本假设被控电脑是 16:9 全屏，会按 16:9 参考尺寸裁剪画面并弹比例告警。
手机画面比例由设备决定（常见 20:9 竖屏），照搬会把画面切掉 —— 手机投屏模式下改为
直接抓整个客户区，并只记录尺寸不告警。

### 4. 不尝试启动本机游戏

鸣潮跑在手机上，本机没有可启动的 exe。投屏窗口没打开时，日志会明确提示
「游戏在手机上运行，本机不启动游戏；请确认 NectarLink 的手机投屏窗口已打开」，
而不是含糊的「游戏路径不存在」。

### 5. 手机端下载入口

新增全局配置「手机投屏(NectarLink)」，带一个**「下载手机端(网盘)」按钮**和地址栏，
点按钮直接打开网盘分享页：


## 你需要做的

1. **手机端**：点配置里的「下载手机端(网盘)」按钮，下载 NectarLink 的 Android 客户端装到手机上，
   与电脑配对（桌面端扫码即可）。
2. **桌面端**：NectarLink 里打开手机投屏窗口，确认能看到手机上的鸣潮画面。
3. **ok-ww 配置**：在「远控串流窗口(试验性)」里把 `Enable` 打开、`Preset` 选
   **「NectarLink 手机投屏」**，保存后重启 ok-ww。
4. **键位映射**（在手机端 NectarLink 里设置）：把切人键绑到 **1 / 2** 两个键，
   技能/交互按需要绑定。ok-ww 在手机投屏下发的就是真实键盘事件，会被 NectarLink 转发到手机。
5. **编队**：建议在「MuMu 安卓 Config」里用三个「编队角色」下拉点选实际队伍
   （换队立即生效、不依赖画面识别）。
6. **窗口**：投屏窗口要保持**在前台**（Pynput 只往前台窗口发输入），也别最小化。

## 已知限制

- 投屏有编码与网络延迟，识图阈值可能要比本地 PC 放宽一点；游戏本身卡顿时脚本会跟着慢。
- 投屏窗口必须在前台，否则点击/按键不生效（Pynput 的限制，与普通远控窗口一致）。
- 切人键 1/2 依赖手机端 NectarLink 的键位映射；没绑定的话切人不会有反应。
- 本版不做实机验证（按你的要求），投屏与切人效果由你确认。
